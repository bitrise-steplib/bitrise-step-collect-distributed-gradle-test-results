# Collect Distributed Gradle Test Results

[![Step changelog](https://shields.io/github/v/release/bitrise-steplib/bitrise-step-collect-distributed-gradle-test-results?include_prereleases&label=changelog&color=blueviolet)](https://github.com/bitrise-steplib/bitrise-step-collect-distributed-gradle-test-results/releases)

Collect test results from distributed Gradle builds

<details>
<summary>Description</summary>

This Step collects test results from distributed Gradle builds and uploads them to Bitrise.

</details>

## 🧩 Get started

Add this step directly to your workflow in the [Bitrise Workflow Editor](https://docs.bitrise.io/en/bitrise-ci/workflows-and-pipelines/steps/adding-steps-to-a-workflow.html).

You can also run this step directly with [Bitrise CLI](https://github.com/bitrise-io/bitrise).
